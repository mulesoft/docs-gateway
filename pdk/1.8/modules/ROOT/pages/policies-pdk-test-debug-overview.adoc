include::_attributes.adoc[]

:imagesdir: ../assets/images

Use the Policy Development Kit (PDK) testing options to validate behavior, catch regressions, and debug before you xref:policies-pdk-publish-policies-overview.adoc[publish your policy to Exchange]:

* xref:policies-pdk-debug-local.adoc[] — Use the preconfigured API instance in your project’s `playground` directory to exercise and debug the policy interactively.
* xref:policies-pdk-unit.adoc[]: Run fast, deterministic Rust unit tests that exercise the full request and response lifecycle without configuring Envoy, WebAssembly, or external services.
* xref:policies-pdk-integration-tests.adoc[]: Run automated tests on a local mode Flex Gateway to verify your policy with real gateway behavior and surrounding configuration.
