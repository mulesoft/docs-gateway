For Omni Gateway running in Local Mode, you apply API policies using xref:local-configuration-reference-guide.adoc[local declarative configuration files]. You specify the location of these configuration files when you first run Omni Gateway.

See xref:local-reg-run.adoc[] for more information about how to start the gateway.
