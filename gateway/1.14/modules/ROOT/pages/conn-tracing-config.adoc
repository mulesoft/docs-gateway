* xref:conn-tracing-config.adoc#runtime-manager-config[Runtime Manager runtime configurations]: Applies to all API instances in the gateway.
* xref:conn-tracing-config.adoc#yaml-resource-config[Configuration YAML resource]: Applies to all API instances.
* xref:conn-tracing-config.adoc#policy-config[Policy]: Applies to one API instance and provides granular control.
