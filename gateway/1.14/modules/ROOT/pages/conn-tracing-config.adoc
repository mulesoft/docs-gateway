[[export-traces]]
== Export Traces to Third-Party Services

Export Omni Gateway distributed tracing data to third-party observability and analytics platforms, such as Azure Monitor, Splunk HEC, or any OpenTelemetry-compliant tool.

Export traces from Omni Gateway in Connected Mode using one of these methods:

* xref:conn-tracing-config.adoc#export-otel-endpoint[OpenTelemetry endpoint]: Omni Gateway sends traces directly to a gRPC or HTTP OpenTelemetry endpoint.
* xref:conn-tracing-config.adoc#export-otel-traces-from-monitoring-telemetry-exporter[Anypoint Monitoring Telemetry Exporter]: Omni Gateway sends traces to Anypoint Monitoring, and the Telemetry Exporter forwards them to third-party providers.

[[export-otel-endpoint]]
=== Export Traces to an OpenTelemetry Endpoint

Edit and apply a YAML configuration resource with the `opentelemetry` provider type to send traces directly from Omni Gateway to an OpenTelemetry endpoint. This configuration resource applies to all API instances in the gateway.
