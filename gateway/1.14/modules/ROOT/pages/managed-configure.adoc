* xref:managed-inbound-tls-config.adoc[] - CloudHub 2.0 private spaces and OpenShift routes on Runtime Fabric enable you to protect your API instances with inbound TLS.
* xref:managed-outbound-tls-config.adoc[] - Managed Omni Gateway enables you to configure TLS and mTLS contexts for each upstream, and to trust upstreams signed by a private CA.
* xref:managed-timeout.adoc[] - Managed Omni Gateway on CloudHub 2.0 enables you to configure default timeout settings for your runtime and APIs.
* xref:managed-tracing-config.adoc[] - Managed Omni Gateway on CloudHub 2.0 enables you to configure distributed tracing.
* xref:managed-forward-proxy.adoc[] - Managed Omni Gateway on Runtime Fabric enables you to route outbound connections through a forward proxy.
