Export Omni Gateway distributed tracing data to third-party observability and analytics platforms, such as Azure Monitor, Splunk HEC, or any OpenTelemetry-compliant tool.

Export traces from Omni Gateway in Connected Mode using one of these methods:

* xref:conn-export-traces.adoc#export-otel-endpoint[OpenTelemetry endpoint]: Omni Gateway sends traces directly to a gRPC or HTTP OpenTelemetry endpoint.
* xref:conn-export-traces.adoc#export-otel-traces-from-monitoring-telemetry-exporter[Anypoint Monitoring Telemetry Exporter]: Omni Gateway sends traces to Anypoint Monitoring, and the Telemetry Exporter forwards them to third-party providers.

== Before You Begin

Configure distributed tracing for the gateway. See xref:conn-tracing-config.adoc[].

== Export Traces to an OpenTelemetry Endpoint
