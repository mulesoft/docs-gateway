// tag::bufferLimit[]
Buffered payloads count toward the Omni Gateway payload limit, which is 1 MB by default. To change the limit on a self-managed Omni Gateway, set the `FLEX_DOWNSTREAM_CONNECTION_BUFFER_LIMIT_BYTES` environment variable. In Connected Mode, you can also set *Global connection buffer limit* in Runtime Manager. For more information, see xref:conn-env-variables.adoc#runtime-manager-global-routing[Configure Global and Routing Settings in Runtime Manager]. You can't change the limit on a managed Omni Gateway. For more information about the limit, see xref:review-prerequisites.adoc#limits[Omni Gateway Limits and Performance Metrics].
// end::bufferLimit[]
