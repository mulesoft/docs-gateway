About support for custom auth - customers can remove the client id validation policy from LLM Proxy and add their custom auth policy. But they need to make sure that Authentication.clientName is populated so that requests and tokens will be attributed to that client in the reports.
[11:58 AM]llm proxy core policy config taken the client name param as input. By default that is Authentication.clientName but that can be overriden with anything they want.
