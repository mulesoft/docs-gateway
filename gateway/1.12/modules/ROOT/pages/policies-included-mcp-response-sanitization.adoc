== Summary

The MCP Response Sanitization policy reduces LLM token consumption by transforming MCP `tools/call` responses before they are returned to the client. Transformations include converting HTML to Markdown, stripping base64-encoded data, optionally removing JSON fields with null values, and normalizing excessive whitespace.

The policy processes responses when:

* The upstream response has `Content-Type` `application/json` or `text/event-stream` (SSE).
* The body is a JSON-RPC MCP `tools/call` result (including streamed SSE events that carry those results).

Responses smaller than the configured minimum size skip transformation so tiny payloads are not altered.

When transformations reduce estimated token usage on a JSON response, the policy can inject token metrics into the response body for xref:policies-included-mcp-support.adoc[MCP Support] to consume and emit; MCP Support strips that metadata before the client receives the final payload.

[%header%autowidth.spread,cols="a,a"]

|===
| Element | Description
| HTML to Markdown | When `true`, converts HTML content in tool results to Markdown. Default is `true`.
| Strip Base64 | When `true`, detects and removes base64-encoded data from tool results. Default is `true`.
| Remove Nulls | When `true`, removes JSON fields whose value is null. Default is `false`.
| Collapse Whitespace | When `true`, normalizes excessive whitespace in text content. Default is `true`.
| Min Response Size (bytes) | Minimum response size in bytes for transformation to run. Responses smaller than this value are passed through unchanged. Default is `500`. Minimum value is `0`.
| Per-Tool Overrides | Optional list of overrides keyed by MCP tool name. Each override can set `html_to_markdown`, `strip_base64`, `remove_nulls`, and `collapse_whitespace` for that tool. Tools without an override use the global defaults.
|===

[[tool-overrides]]
=== Per-tool overrides

Each override entry requires `tool_name`, matching the MCP tool name from the `tools/call` request. Optional boolean fields match the global parameters. If you omit a field in an override, that transform falls back to the corresponding value from the global policy configuration (not the schema default alone).
