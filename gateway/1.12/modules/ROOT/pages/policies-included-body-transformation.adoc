== Summary

The Body Transformation policy transforms request or response body content with a DataWeave script. The script receives `attributes.headers` and `payload`. The gateway streams body processing. If the script declares an output MIME type such as `output application/json`, the gateway uses it for the transformed response. Otherwise the gateway keeps the original `Content-Type`. In the request or response, the gateway processes the body in streaming mode and updates `Content-Type` and `Content-Length` after transformation.

== Configure Policy Parameters

The DataWeave script receives `attributes.headers` and `payload`. Declare the output MIME type in the script when needed, such as `output application/json`.

In Local Mode, apply the policy via declarative configuration using the `body-transformation-flex` policy. In Managed Flex Gateway and Flex Gateway Connected mode, apply the policy from the UI and select the body transformation type.

include::partial$policy-title-headers.adoc[tag=configFileTitleOnly]

----
- policyRef:
    name: body-transformation-flex
  config:
    script: <string>        // REQUIRED - DataWeave script
    requestFlow: <string>   // REQUIRED - "onRequest" or "onResponse"
----

[%header%autowidth.spread,cols="a,a,a,a"]
|===
|Parameter | Required or Optional | Default Value | Description

| `script`
| Required
| —
| A DataWeave script that transforms the body. The script receives `attributes.headers` and `payload`. Declare the output MIME type in the script when needed, such as `output application/json`.

| `requestFlow`
| Required
| —
| The phase when the policy runs: `onRequest` for the request body, or `onResponse` for the response body.
|===

=== Resource Configuration Example

The following example transforms the request payload to a new structure that includes the value from the custom header `custom-client-header` and fields from the payload.

----
  policies:
    - policyRef:
        name: body-transformation-flex
      config:
        script: |
          {
            "id": attributes.headers.'custom-client-header',
            "username": payload.name ++ payload.surname
          }
----

To transform the response body and set a custom output format such as XML, declare the output and use `requestFlow: onResponse`:

----
  policies:
    - policyRef:
        name: body-transformation-flex
      config:
        script: |
          output application/xml
          ---
          {
            "trace": payload.headers.'X-Amzn-Trace-Id',
            "custom-data": "custom-value"
          }
        requestFlow: onResponse
----
