== Configure Timeouts in Runtime Manager

To configure timeout defaults for a Managed Flex Gateway in Runtime Manager:

. In Anypoint Platform, select *Runtime Manager*.
. Select *Flex Gateways*.
. Select your Managed Flex Gateway.
. Open *Runtime Configurations*.
. Open *Timeouts*.
. Set values for *Stream Idle Timeout*, *Upstream Connection Idle Timeout*, and *Upstream Response Timeout*.
. Apply the changes.

== Configure Timeouts During Managed Gateway Deployment

You can also set timeout values during the Managed Flex Gateway setup flow.
For deployment steps, see xref:flex-gateway-managed-set-up.adoc[].
