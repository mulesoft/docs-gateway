Managed Flex Gateway supports default timeout settings for all deployed APIs.
You can configure these values when you deploy the gateway and update them later in Runtime Manager.

Managed Flex Gateway supports these timeout settings:

* Stream Idle Timeout: The maximum idle time for a stream in either direction.
* Upstream Connection Idle Timeout: The maximum idle time for a connection between Flex Gateway and an upstream.
* Upstream Response Timeout: The maximum time Flex Gateway waits for a response from an upstream.

== Configure Timeouts in Runtime Manager

To configure timeout defaults for a Managed Flex Gateway in Runtime Manager:

. In Anypoint Platform, select *Runtime Manager*.
. Select *Flex Gateways*.
. Select your Managed Flex Gateway.
. Open *Runtime Configurations*.
. Open *Timeouts*.
. Set your values for *Stream Idle Timeout*, *Upstream Connection Idle Timeout*, and *Upstream Response Timeout*.
. Apply the changes.

== Configure Timeouts During Managed Gateway Deployment

You can also set timeout values during deployment in the Managed Flex Gateway setup flow.
For deployment steps, see xref:flex-gateway-managed-set-up.adoc[].
