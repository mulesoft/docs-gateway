== Summary

The OAuth 2.0 On-Behalf-Of (OBO) Credential Injection policy exchanges an incoming bearer token for a new token to target specific upstream services by using the OAuth 2.0 Token Exchange RFC 8693 protocol. This policy is applied to outbound traffic (gateway to the backend service) to automatically exchange the OAuth 2.0 token needed for backend services. 

The policy extracts the Bearer token from the incoming request's Authorization header and sends an RFC 8693 compliant request to the token exchange service. The policy then replaces the Authorization header with the new token returned from the token exchange service and forwards the modified request to the backend service.

|===
|Parameter |Description

|Client ID |OAuth 2.0 client ID for token exchange.

|Client Secret |OAuth 2.0 client secret for token exchange.

|Token Endpoint |OAuth 2.0 token endpoint URL. The service must support RFC 8693 Token Exchange.

|Target Type |Parameter type for specifying the target service. Supported values:

* Audience: Logical identifier of the target service
* Resource: physical URI of the target resource defined in RFC 8707 format
|Target Value |Target audience URI or resource URI for the exchanged token.

|Scope |OAuth 2.0 scope to request for the exchanged token.

|Timeout |Timeout for token exchange requests in milliseconds.
|===
