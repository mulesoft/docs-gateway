== Distributed Tracing Configuration Options

You can enable distributed tracing for your Managed Flex Gateway, and you can configure the percentage of requests that are traced.

If you enable distributed tracing, you can override the percentage of requests that are traced by applying the Tracing Policy to specific APIs.
For more information, see xref:policies-included-tracing.adoc[Tracing Policy].
