== Enable Distributed Tracing with a YAML Configuration Resource

Edit and then apply this configuration resource to enable distributed tracing. This configuration resource applies to all API instances.
This example sets sampling to 0 for all traces, and sampling will be configured on a per-API basis using policies.

[source,yaml]
----
apiVersion: gateway.mulesoft.com/v1beta1
kind: Configuration
metadata:
  name: tracing
  namespace: test-ns
spec:
  tracing:
    provider:
      type: anypoint
      properties:
        timeout: 10s
    sampling:
      client: 0   # no sampling - for the case where you want to configure sampling on a per-API basis using the Tracing policy.
      random: 0   # no sampling - for the case where you want to configure sampling on a per-API basis using the Tracing policy.
      overall: 0  # no sampling - for the case where you want to configure sampling on a per-API basis using the Tracing policy.
      # # Add labels such as these example labels,if you want to configure labels globally. You can also configure labels on a per-API basis using the Tracing policy.
      # labels:
      # - name: c-env-tag
      #   type: environment
      #   keyName: FLEX_NAME
      #   defaultValue: DEFAULT_VAL
      # - name: c-header-tag
      #   type: requestHeader
      #   keyName: :method
      #   defaultValue: DEFAULT_METHOD
      # - name: c-literal-tag
      #   type: literal
      #   defaultValue: the-tag     
----
