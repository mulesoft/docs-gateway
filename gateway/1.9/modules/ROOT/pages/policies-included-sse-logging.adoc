== Summary

The SSE Logging policy enables logging for SSE connections.

NOTE: This policy only provides logs for SSE events. To log request information, see xref:policies-included-message-logging.adoc[].

== Configuring Policy Parameters

include::partial$policy-title-headers.adoc[tag=configFileTitleOnly]

|===
| Element | Description
| Logs | List of logs executed on every SSE event.
| DataWeave expression for SSE response messages | DataWeave Expression that extracts information from the SSE Event. Use `#[payload]` for the event's payload, `#[vars.data]` for the event data, and `#[vars.id]` for the event ID.
| Category | String prefix to add to each log message.
| Level | Message log level.
|===
