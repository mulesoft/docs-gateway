Flex Gateway provides the following guides to quickly get started with Anypoint Flex Gateway. The tutorial describes how to deploy a Flex Gateway and publish a simple API that is secured with a basic authentication policy. See the guide for you desired Flex Gateway deployment type:

* xref:flex-gateway-managed-getting-started.adoc[] - Deploy Managed Flex Gateway to CloudHub 2.0.
* xref:flex-gateway-getting-started.adoc[] - Deploy a Self-Managed Flex Gateway to a Docker container on your local infrastructure.
* xref:flex-gateway-k8-getting-started.adoc[] - Deploy a Self-Managed Flex Gateway to a Kubernetes pod on your local infrastructure.
