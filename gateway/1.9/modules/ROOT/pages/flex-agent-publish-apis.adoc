For Managed Flex Gateway or Flex Gateway running in Connected Mode, use *API Manager* to publish both API instances with a single upstream service and API instances with multiple upstream services. 

For more information, see xref:api-manager::create-instance-task-flex.adoc[].

Additionally, you can publish a simple API with xref:flex-gateway-managed-getting-started.adoc[] or xref:flex-gateway-getting-started.adoc[Getting Started with Self-Managed Flex Gateway in Connected Mode].
