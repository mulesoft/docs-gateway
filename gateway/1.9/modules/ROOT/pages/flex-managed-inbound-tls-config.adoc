For Managed Flex Gateway deployed on CloudHub 2.0, the CloudHub 2.0 private space manages the inbound TLS. 

To configure a TLS context for the private space you're deploying your Managed Flex Gateway to, see xref:cloudhub-2::ps-config-domains.adoc[].

Configuring a TLS context for your private space means all APIs deployed to Managed Flex Gateways in the private space are HTTPS and secure.

To configure outbound TLS context, see xref:flex-managed-outbound-tls-config.adoc[].
