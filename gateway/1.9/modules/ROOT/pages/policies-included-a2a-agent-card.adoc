== Summary

The A2A Agent Card Policy rewrites the URL in the A2A Agent Card responses= so that the exposed URL points to the public endpoint of the Flex Gateway A2A server instance, rather than directly to backend services. This ensures that all client requests are routed through Flex Gateway, enabling it to enforce security and access controls while preventing direct access to backend resources.

There are no configuration parameters required for this policy.
