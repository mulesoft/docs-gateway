For Managed Flex Gateway or Flex Gateway running in Connected Mode, use *API Manager* to publish both API instances with a single upstream service, API instances with multiple upstream services, MCP server instances, and A2A server instances. 

For more information, see:

* xref:api-manager::create-instance-task-flex.adoc[]
* xref:api-manager::create-instance-task-mcp.adoc[]
* xref:api-manager::create-instance-task-a2a.adoc[]

Additionally, you can publish a simple API with xref:flex-gateway-managed-getting-started.adoc[] or xref:flex-gateway-getting-started.adoc[Getting Started with Self-Managed Flex Gateway in Connected Mode].
