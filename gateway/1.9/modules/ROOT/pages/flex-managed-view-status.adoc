== View Managed Flex Gateway Status 

To view information about a Managed Flex Gateway Instance:

. From Anypoint Platform, select *Runtime Manager*.
. Select *Flex Gateways* in the navigation menu.
. Select the name of the Managed Flex Gateway whose status you want to view.

The *Dashboard* shows the status for the gateway.
