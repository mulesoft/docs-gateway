== View a Managed Flex Gateway Metrics in Runtime Manager

To view information about a Managed Flex Gateway Instance:

. From Anypoint Platform, select *Runtime Manager*.
. Select *Flex Gateways* in the navigation menu.
. Select the name of the Managed Flex Gateway to view its status.

The *Dashboard* shows information about the gateway, such as:

* Gateway Information

** *Status*
** *Public endpoint*
** *Last updated*
** *Internal endpoint*
** *Private space*

* Gateway Usage

** *APIs capacity*
** *API requests*
** *Data consumed*

* Key Gateway metrics

** *Average CPU usage*
** *Average memory usage*
** *Average latency*
** *API requests*
** *Error count*
