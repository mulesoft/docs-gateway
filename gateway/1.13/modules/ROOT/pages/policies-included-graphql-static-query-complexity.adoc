== Summary

The GraphQL Static Query Complexity policy analyzes each GraphQL operation against your API schema and assigns costs using schema directives, default field weights, and optional argument multipliers. If the estimated score exceeds `maximumComplexity`, Flex Gateway blocks or logs the request based on the *Block request* setting. Because simple structural limits alone don't capture weighted costs, this policy honors `@cost`-style directives on fields and scales totals if callers supply sizes such as `first` or `limit`.

If `source` is `context`, Flex Gateway pulls the SDL from your API asset in Exchange. If `source` is `inline`, Flex Gateway reads the inline SDL. Mark expensive fields in the SDL with your configured directive name, usually `@cost`. To ensure that Flex Gateway adjusts totals from caller arguments, align the value and multiplier argument names with this policy.

After Flex Gateway extracts inline GraphQL operation text from the request, the policy runs analysis. If Flex Gateway can't resolve normal operation text, such as persisted query flows, it skips analysis.

Although the schema loads into memory, Flex Gateway logs a warning and forwards the request instead of enforcing complexity.

If you turn off *Block request* and complexity fails after parsing, Flex Gateway logs a warning and forwards the request upstream. If you turn on *Block request*, Flex Gateway returns a 400 Bad Request message with `Content-Type: application/json` and a JSON body such as `{"errors":[{"message":"{reason}"}]}`. If Flex Gateway can't parse the operation text, it returns a 400 error, even if you disable *Block request*.

If you enable R*eject unbounded lists*, Flex Gateway rejects queries that reach list fields without limiting arguments that match your configured cost directives.

Use this policy on Flex Gateway API instances that expose a GraphQL interface. Apply it at the API or resource scope as needed.

== Configuring Policy Parameters

include::partial$policy-title-headers.adoc[tag=configFile]

----
- policyRef:
    name: graphql-static-query-complexity-flex
  config:
    maximumComplexity: <number> // REQUIRED, must be positive
    source: <string> // OPTIONAL, default: context; values: "context" or "inline"
    schema: <string> // REQUIRED when source is inline; omit when source is context
    defaultFieldCost: <number> // OPTIONAL, default: 1.0, must be >= 0
    blockOperation: <boolean> // OPTIONAL, default: true
    rejectUnboundedLists: <boolean> // OPTIONAL, default: true
    directiveName: <string> // OPTIONAL, default: cost
    valueArgument: <string> // OPTIONAL, default: weight
    multipliersArgument: <string> // OPTIONAL, default: multipliers
----

[%header%autowidth.spread,cols="a,a,a,a"]
|===

| Parameter | Required or Optional | Default Value | Description

| `maximumComplexity`
| Required
| None
| Positive numeric ceiling for the estimated complexity score.

| `source`
| Optional
| `context`
| `context` pulls SDL from the API asset in Exchange. `inline` embeds SDL in configuration for Local Mode or environments without Exchange-backed metadata.

| `schema`
| Required when `source` is `inline`
| Omit for `context`
| The full GraphQL SDL text. To use inline configuration, you must provide this field.

| `defaultFieldCost`
| Optional
| `1.0`
| The base cost Flex Gateway applies to fields that don't declare your cost directive.

| `blockOperation`
| Optional
| `true`
| If `true` and analysis reports a violation after a successful parse, Flex Gateway returns a 400 error. If Flex Gateway can't parse the query, it returns a 400 error regardless of this flag.

| `rejectUnboundedLists`
| Optional
| `true`
| If `true`, Flex Gateway rejects queries that hit list fields without limiting arguments that align with your directive configuration.

| `directiveName`
| Optional
| `cost`
| The SDL directive name that Flex Gateway reads for per-field costs.

| `valueArgument`
| Optional
| `weight`
| Directive argument that carries the base weight for a field.

| `multipliersArgument`
| Optional
| `multipliers`
| Directive argument that lists which operation arguments multiply cost, such as list sizes.

==== Resource Configuration Example

This example caps total complexity at 250, keeps default weights, and uses inline SDL.

[source,yaml]
----
- policyRef:
    name: graphql-static-query-complexity-flex
  config:
    source: inline
    maximumComplexity: 250
    blockOperation: true
    rejectUnboundedLists: true
    schema: |
      directive @cost(weight: Int!, multipliers: [String!]) on FIELD_DEFINITION

      type Query {
        users(limit: Int): [User!]! @cost(weight: 1, multipliers: ["limit"])
        version: String!
      }

      type User {
        id: ID!
        name: String!
      }
----

[NOTE]
====
To start the policy, supply a populated configuration payload. 

In Anypoint Platform, to ensure that Flex Gateway automatically fetches costs and multipliers, attach the annotated GraphQL SDL to the API asset in Exchange. In Local Mode, because `source: context` requires the API asset metadata that Managed and Connected environments usually publish, set `source` to `inline` and provide your `schema` text and a positive `maximumComplexity`. 

To limit abuse, Flex Gateway caps complexity analysis at 10,000 query nodes per operation.
====
