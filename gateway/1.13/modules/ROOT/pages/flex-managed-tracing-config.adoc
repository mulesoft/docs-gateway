== Enable and Configure Distributed Tracing for your Managed Omni Gateway

To enable distributed tracing for your Managed Omni Gateway:

. From Anypoint Platform, select *Runtime Manager > Omni Gateways*.
. Click the Managed Omni Gateway name.
. In the navigation menu, click Settings.
. Click *Advanced options*.
. Click *Tracing*.
. Turn on *Distributed tracing*.
. Set the *Sampling percentage* to the percentage of transactions that you want to trace.
** This setting corresponds to the `overall` sampling percentage. The `client` and `random` sampling percentages are set to 100% by default, if the sampling percentage is set to a non-zero value here.
** Set the *Sampling percentage* to 0 if you want to specify the sampling percentage only on a per-API basis, using the Tracing policy.
. Click *Apply Changes*.
