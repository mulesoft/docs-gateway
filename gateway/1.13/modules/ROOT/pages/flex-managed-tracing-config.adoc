Configure distributed tracing for Managed Omni Gateway using one of these methods:

* xref:flex-managed-tracing-config.adoc#managed-deployment-config[Managed Omni Gateway deployment]: Set initial distributed tracing values when you create the gateway.
* xref:flex-managed-tracing-config.adoc#runtime-manager-config[Runtime Manager runtime configurations]: Applies to all API instances in the gateway after the gateway is deployed.
* xref:flex-managed-tracing-config.adoc#policy-config[Policy]: Applies to one API instance and provides granular control.
