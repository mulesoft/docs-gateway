Use Anypoint Monitoring to see both runtime and access logs. Use the Anypoint Monitoring filtering to see different detailed logging views.

To access Anypoint Monitoring from the Runtime Manager Omni Gateway UI:

. From Anypoint Platform, select *Runtime Manager*.
. Select *Omni Gateways* in the navigation menu.
. Click the name of the Omni Gateway whose logs you want to view.
. Click *Logs*.
. Click *View logs in Anypoint Monitoring*.
+
This action takes you to the Anypoint Monitoring UI.
