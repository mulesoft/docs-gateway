Omni Gateway running in Local Mode enables you to monitor APIs independent of Anypoint Platform. Using declarative configuration files, you configure Omni Gateway to deliver logs to different Fluent Bit outputs.

Refer to the following tasks for details about monitoring in Local Mode:

* xref:flex-local-third-party-logs-config.adoc[Configure External Logs for Omni Gateway in Local Mode] - Configure log output for Fluent Bit output types. Output types include `File`, `HTTP`, and `Splunk`.
* xref:flex-local-view-logs.adoc[View Standard Output Logs] - View Omni Gateway standard output logs. Quickly verify the status of external services and API requests.
