== Summary

The A2A V1 Agent Card Policy rewrites the JSON-RPC interface URL in the A2A v1.0 agent card to match the gateway's public address. This policy applies only to A2A v1.0 traffic and ensures that clients connect through the gateway rather than directly to backend agents.
