== Summary

The A2A Schema Validation policy validates that every request to the A2A server complies with the A2A schema. If validation fails it will report a Policy Violation.

There are no configuration parameters for this policy.

include::partial$policy-title-headers.adoc[tag=configFileTitleOnly]

The A2A Schema Validation policy isn't supported in Local Mode.
