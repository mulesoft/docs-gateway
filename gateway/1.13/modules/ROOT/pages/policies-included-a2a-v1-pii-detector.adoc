== Summary

The A2A V1 PII Detector policy detects personally identifiable information (PII) in A2A v1 requests across all transports (JSON-RPC, HTTP+JSON, gRPC). If PII is detected, you can either log or block the request. A policy violation is always reported if PII is detected.
