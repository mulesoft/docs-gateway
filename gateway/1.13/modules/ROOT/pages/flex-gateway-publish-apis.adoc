= Publishing Omni Gateway API Instances
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]
:imagesdir: ../assets/images

Publishing an API instance consists of defining a client service and routing that service to a backend location. Omni Gateway enables you to publish API instances via Anypoint Platform (Connected Mode) or declarative configuration files (Local Mode).

To publish an API instance in Connected Mode, see xref:flex-gateway-publish-apis-conn.adoc[].

To publish an API instance in Local Mode, see xref:flex-gateway-publish-apis-local.adoc[].
