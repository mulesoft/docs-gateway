== Summary

The Correlation ID Override policy enables you to override the global correlation ID parameters for an API. Use this policy to change the name of the header that carries the correlation ID and how Omni Gateway generates the ID when a request doesn't include one.

== Before You Begin

This policy overrides the global correlation ID configuration for an API. Before you apply this policy, decide:

* The name of the request header that carries the correlation ID.
* The expression that generates the correlation ID when a request doesn't include the header.

=== Basic Configuration

[%header%autowidth.spread,cols="a,a,a"]
|===
| Element | Required | Description

| Header
| Yes
| Name of the request header that carries the correlation ID. If the request doesn't include this header, Omni Gateway generates a correlation ID and adds the header to the request.

| Generation Expression
| Yes
| Expression that generates the correlation ID when the request doesn't include the header. For example, `prefix(uuid(), 'REQ-')`.

See <<generation-expressions>> for the supported functions.

|===

== How This Policy Works

When you apply the Correlation ID Override policy to an API, the policy replaces the global correlation ID settings for that API.

For each request, Omni Gateway checks for the header you configure in the Header field:

* If the request includes the header, Omni Gateway uses the value as the correlation ID.
* If the request doesn't include the header, Omni Gateway generates a correlation ID by evaluating the Generation Expression and adds the header to the request.

[[generation-expressions]]
=== Generation Expressions

A generation expression can use the following functions:

[%header%autowidth.spread,cols="a,a"]
|===
| Function | Description

| `uuid()`
| Generates a unique identifier.

| `timestamp()`
| Generates a timestamp.

| `concat(a, b, ...)`
| Joins two or more values into one value.

| `replace(str, from, to)`
| Replaces text in a value.

| `prefix(expr, str)`
| Adds text to the beginning of the value of an expression.

| `suffix(expr, str)`
| Adds text to the end of the value of an expression.

|===

== Example Configurations

The following examples demonstrate common configuration patterns for the Correlation ID Override policy.

=== Generate a UUID

In the following example, requests that don't include the `x-correlation-id` header receive a generated UUID.

----
- policyRef:
    name: correlation-id-override-flex
  config:
    header: "x-correlation-id"
    generationExpression: "uuid()"
----

=== Add a Prefix to the Generated ID

In the following example, requests that don't include the `x-request-id` header receive a generated UUID that begins with `REQ-`.

----
- policyRef:
    name: correlation-id-override-flex
  config:
    header: "x-request-id"
    generationExpression: "prefix(uuid(), 'REQ-')"
----

=== Add a Suffix to the Generated ID

In the following example, requests that don't include the `x-correlation-id` header receive a generated UUID that ends with `-gw`.

----
- policyRef:
    name: correlation-id-override-flex
  config:
    header: "x-correlation-id"
    generationExpression: "suffix(uuid(), '-gw')"
----
