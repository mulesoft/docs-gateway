* xref:managed-tls-config.adoc[] - Managed Omni Gateway enables you to configure default inbound and outbound TLS contexts, TLS and mTLS contexts for each upstream, inbound TLS on CloudHub 2.0 and Runtime Fabric, and trust for upstreams signed by a private CA.
* xref:managed-timeout.adoc[] - Managed Omni Gateway on CloudHub 2.0 enables you to configure default timeout settings for your runtime and APIs.
* xref:managed-forward-proxy.adoc[] - Managed Omni Gateway on Runtime Fabric enables you to route outbound connections through a forward proxy.
