You can configure TLS in Connected Mode via:

* API Manager: Applies a TLS context to one API instance or upstream service.
* Runtime Manager runtime configurations: Applies default TLS contexts to all API instances and upstream services in the gateway.
* Configuration YAML resource: Applies default TLS contexts to all API instances and upstream services in the gateway.
