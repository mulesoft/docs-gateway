== Summary

The API Log Level policy overrides the runtime log level for a single API. The runtime log level controls how much detail Omni Gateway writes to the runtime logs. By default, every API uses the global runtime log level. Use this policy to set a different level for one API, so you can change the detail of its runtime logs without affecting any other API.

Use this policy when you want to:

* Set the level to `debug` or `trace` for an API that you're troubleshooting, so you can see detailed runtime logs for that API without increasing the detail of the runtime logs for every API.
* Set the level to `warn` or `error` for an API that writes more runtime log messages than you need, so you can reduce noise and keep the logs for other APIs unchanged.
* Set the level to `info` for an API after you finish troubleshooting, so the API returns to a standard level of detail.

This policy applies to runtime logs only. It doesn't change access logs.

| Required
| N/A

[[log-levels]]
== Log Levels

The following table lists the supported levels from the most detailed to the least detailed.

[%header%autowidth.spread,cols="a,a"]
|===
| Level | Description

| `trace`
| Writes the most detailed runtime logs, and all messages from the levels that follow.

| `debug`
| Writes detailed runtime logs for troubleshooting, and all messages from the levels that follow.

| `info`
| Writes general runtime log messages, warnings, and errors.

| `warn`
| Writes warnings and errors.

| `error`
| Writes errors only.

|===

== Example Configurations

The following examples demonstrate common configuration patterns for the API Log Level policy.

=== Troubleshoot an API

In the following example, the API writes detailed runtime logs while the global runtime log level stays the same for all other APIs.

----
- policyRef:
    name: api-log-level-flex
  config:
    level: "debug"
----

=== Reduce Runtime Log Output

In the following example, the API writes only errors to the runtime logs.

----
- policyRef:
    name: api-log-level-flex
  config:
    level: "error"
----
