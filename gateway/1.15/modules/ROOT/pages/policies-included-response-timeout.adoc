== Summary

The Response Timeout policy sets how long Omni Gateway waits for a response from an upstream service before it returns a `504` error. The timer starts when Omni Gateway sends the request to the upstream service.

Without this policy, an API instance uses the gateway-level Upstream Response Timeout. The gateway-level default is 15 seconds.

This policy overrides every other Upstream Response Timeout configuration for the API instance you apply it to, whether the policy value is higher or lower. To change the gateway-level timeout, see xref:managed-timeout.adoc[] or xref:conn-timeout.adoc[].
