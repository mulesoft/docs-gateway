[[no-permissions]]
== Performing Registration as a User Without Necessary Access Permissions

Executing the registration command without having correct permissions can result in an error:
----
Couldn't execute register command successfully: rpc error: code = Internal desc = handler returned neither error nor response message
----

=== Cause

This issue occurs when the credentials that you provide for registration do not have the required permissions.

=== Solution

To resolve this error, perform the following steps: 

. Navigate to *Access Management* as the organization administrator. 
. Select *Users* from the main menu.
. Select the target organization user from the *Users* menu.
. From the *Permissions* tab, select *Runtime Manager*.
. Specify the environment in which to apply your permissions.
. Select the following from the *Select access* dropdown menu:
* _Manage Servers_
* _Read Servers_
. Click the *+* button.

Re-running the registration command should now result in success.

[[renew-deleted-gateway]]
== Renewing the Registration of a Deleted Gateway

Running `flexctl registration renew` with the registration file of a gateway that was deleted in Runtime Manager results in an error that starts with:

----
invalid response: HTTP/1.1 409 Conflict
----

=== Cause

A deleted gateway's registration can't be renewed. Deleting a gateway in Runtime Manager also removes its configuration history, which you can't recover.

=== Solution

Replace the registration with a new one:

. Register a new gateway with a unique name using the `flexctl registration create` command.
+
For instructions, see xref:conn-reg-run.adoc[] or xref:local-reg-run.adoc[].
. Run Omni Gateway with the new `registration.yaml` file, replacing the old registration file on every replica.
+
For Omni Gateway running in Kubernetes, run the `helm upgrade` command in xref:gateway-renew-certificate.adoc#renew-kubernetes[Renew Registration for Omni Gateway Running in Kubernetes] and pass it the new registration file.
. Assign your APIs to the new gateway.
+
Before Runtime Manager deletes a gateway, you must move its APIs to another gateway or delete them. Move those APIs to the new gateway, or re-create the APIs you deleted.

[[renew-too-old]]
== Renewing a Registration File That Is Too Old

Running `flexctl registration renew` with an old registration file results in this error:

----
The registration file is too old to be renewed. A new registration file is needed
----

=== Cause

The registration file is too old to renew.

=== Solution

Register a new gateway and run Omni Gateway with the new registration file. Follow steps 1 and 2 in <<renew-deleted-gateway>>.
