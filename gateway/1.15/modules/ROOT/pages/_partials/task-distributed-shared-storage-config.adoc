//tag::intro1[]
Enable distributed shared storage for distributed caching, gateway configuration caching (Connected Mode), and rate limiting policies.

Distributed shared storage enables multiple gateway replicas to share state across a distributed deployment.

Distributed shared storage is persistent, but data is lost when all replicas go down (scaled to zero replicas). For persistent shared storage, xref:{page-mode}-shared-storage-config.adoc[configure Redis shared storage].

//end::intro1[]
//tag::intro2[]
You configure distributed shared storage via a storage YAML file.

The following steps demonstrate distributed shared storage support for Omni Gateway running in a Docker container, as a Linux service,
or as a Kubernetes cluster.

//tag::linux[]

[[linux]]
== Configure Shared Storage for Omni Gateway as a Linux service

. Create a folder in the `/usr/local/share/mulesoft/flex-gateway/conf.d` directory and name it `storage`:
+
[source,ssh]
----
sudo mkdir /usr/local/share/mulesoft/flex-gateway/conf.d/storage
----

. Create a YAML configuration file in the `storage` folder:
+
[source,ssh]
----
sudo touch /usr/local/share/mulesoft/flex-gateway/conf.d/storage/shared-storage-config.yaml
----

. Update the file with your distributed shared storage configuration details. For example:
+
[source,ssh]
----
sudo vi /usr/local/share/mulesoft/flex-gateway/conf.d/storage/shared-storage-config.yaml
----
+
. Apply this configuration to all Omni Gateway replicas for them to share data.
//end::linux[]

[[kubernetes]]
== Configure Shared Storage for Omni Gateway in a Kubernetes Cluster

. Create a new resource using a YAML configuration file with your storage details.
. Apply this configuration to all Omni Gateway replicas for them to share data.

//end::k8s[]
//tag::sample-config-all-intro[]
Sample configuration for adding distributed shared storage:
//end::sample-config-all-intro[]
//tag::sample-config-all[]
[source,yaml]
----
apiVersion: gateway.mulesoft.com/v1alpha1
kind: Configuration
metadata:
  name: api-shared-storage
spec:
  sharedStorage:
    objectStore:
      url: distributed://0.0.0.0:30001?join=flex.hostname.com:30001
----

NOTE: You can specify multiple host names in the `join` parameter by separating them with commas. For example: `distributed://0.0.0.0:30001?join=node1.example.com:30001,node2.example.com:30001,192.168.1.10:30001`. The hostname must resolve to the IPs of the Omni Gateway replicas. Firewall rules must allow Omni Gateway replicas to create connections between each other on port 30001.
//end::sample-config-all[]
