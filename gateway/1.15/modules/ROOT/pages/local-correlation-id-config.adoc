Configure a correlation ID in Local Mode using one of these methods:

* xref:local-correlation-id-config.adoc#yaml-resource-config[Configuration YAML resource]: Applies to all API instances in the gateway.
* xref:local-correlation-id-config.adoc#policy-config[Policy]: Applies to one API instance and provides granular control.

include::partial$configuration-precedence.adoc[tags=precedence]

. *Policy*: A policy applied to the API instance.
. *Configuration resource*: Used if no policy value is set.
